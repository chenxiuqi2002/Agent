# 欢迎使用 Obsidian Note Management Agent

这是一个基于 Claude Agent SDK 的 Obsidian 笔记管理助手，运行在本地沙盒环境中，以下是我的全部功能：

## 📝 笔记核心操作（CRUD）
- **创建笔记** - 支持自定义路径、标题、内容和 frontmatter 元数据（标签、时间戳等）
- **读取笔记** - 按相对路径读取笔记内容
- **更新笔记** - 修改笔记内容或元数据，支持追加模式
- **删除笔记** - 删除前会确认
- **移动/重命名笔记** - 改变文件路径
- **搜索笔记** - 按内容或标题进行文本/正则搜索

## 📂 库结构管理
- **列出所有笔记** - 递归列出整个库的笔记
- **获取库结构** - 查看文件夹层级关系
- **创建文件夹** - 组织笔记分类
- **导入文件夹** - 批量导入整个文件夹

## 🔗 链接与图谱分析
- **链接分析** - 分析双向链接，包括出链、入链（反向链接）和未解决引用
- **查找孤立笔记** - 找出没有入链和出链的笔记
- **生成链接图** - 生成 Mermaid 格式的可视化双向链接图
- **生成知识图谱** - 基于标签、链接和内容相似度生成知识关系图
- **查找相关笔记** - 通过标签、链接和内容找到相关笔记

## 🏷️ 标签管理
- **获取所有标签** - 列出库中所有用到的标签及其使用笔记
- **按标签搜索** - 通过标签查找笔记

## 📄 多格式导入（转 Markdown）
- **PDF 导入** - 提取文本、图片和表格转换为 Markdown
- **DOCX 导入** - 提取文本、图片和表格
- **TXT/RTF 导入** - 直接转换文本
- **图片提取** - 从 PDF/DOCX 中提取图片并保存到附件文件夹，生成 `![[图片.png]]` 引用

## 🌐 网络检索与内容增强
- **WebSearch 工具（首选）** - 内置网络搜索，填充最新信息
- **web_search（备选）** - DDGS 库驱动的搜索
- **web_fetch_content** - 抓取特定 URL 的详细内容
- **create_note_with_search** - 一键创建带搜索结果的笔记
- **Defuddle 技能** - 提取网页干净内容，移除导航和广告，节省 Token

## 📊 批量处理与摘要
- **批量摘要** - 对多个笔记生成摘要，输出到新笔记
- **找到相关笔记** - 基于标签、链接和内容相似度推荐关联笔记
- **生成知识图谱** - 输出 Mermaid 图或 JSON 格式的笔记关系图

## 🎨 Obsidian 专用格式支持
- **Obsidian Flavored Markdown** - wikilinks `[[笔记名]]`、嵌入 `![[文件]]`、callouts `> [!tip]`、frontmatter 属性、别名、标签、脚注、注释
- **JSON Canvas（.canvas 文件）** - 创建和编辑可视画布、思维导图、流程图，支持节点、边、分组、颜色、尺寸
- **Obsidian Bases（.base 文件）** - 结构化数据视图（表格、卡片、列表），支持过滤器、公式、摘要、排序、分组

## 🔧 辅助功能
- **附件处理** - 提取的图片自动保存到 `attachments/`，生成 Obsidian 引用链接
- **操作日志** - 所有操作记录审计日志
- **遵循命名规范** - 尊重现有文件夹结构和约定
- **UTF-8 编码** - 确保中文内容正确编码

- list_notes / get_note_structure / create_folder
- search_notes / get_tags
- import_file / import_folder / extract_images
- analyze_links / get_backlinks / find_orphan_notes / find_related_notes
- generate_knowledge_graph / generate_link_graph
- web_search / web_fetch_content / create_note_with_search

## 📚 内置技能（Skill 工具）
- **defuddle** - 网页内容净化提取
- **json-canvas** - Canvas 可视化画布操作
- **obsidian-bases** - Bases 动态视图管理
- **obsidian-cli** - Obsidian CLI 接口
- **obsidian-markdown** - Obsidian 扩展语法指南

## 📍 库信息
- **路径**: `D:\za\Note\Agent\vault`
- **附件**: `D:\za\Note\Agent\vault\attachments`
- **知识图谱**: `D:\za\Note\Agent\vault\.knowledge_graph`

## 快速开始

1. 配置 `.env` 文件中的 `ANTHROPIC_API_KEY`
2. 运行 `docker-compose run obsidian-agent`
3. 用自然语言与 Agent 交互

## 示例命令

- "帮我创建一篇关于 AI 的笔记"
- "搜索所有包含 Python 的笔记"
- "查看 vault 的目录结构"
- "给这篇笔记添加 #技术 标签"
