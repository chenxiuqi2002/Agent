# 震网病毒（Stuxnet）完整技术分析

## 1. 概述
震网病毒是一款里程碑式的恶意软件，被认为是全球首个被证实用于实战的网络战武器。它由不明国家行为体开发，主要目标是破坏伊朗的铀浓缩设施，尤其是纳坦兹核工厂中的离心机。震网通过精密的手段攻击西门子工业控制系统，导致大量离心机因超速运转而物理损坏，但向监控系统谎报一切正常。

## 2. 使用的四大零日漏洞
震网病毒之所以具有极强破坏力，是因为它同时利用了四个**零日漏洞**，实现了自动化、无交互式的传播与权限提升。

| 漏洞编号 | 组件 | 攻击效果 |
|:---|:---|:---|
| CVE-2010-2568 | LNK 快捷方式 | **零交互感染**：用户仅浏览包含恶意LNK文件的U盘或文件夹，即可触发DLL加载和执行。 |
| CVE-2010-2772 | Print Spooler (打印后台程序) | **远程代码执行**：向开放的打印机服务端口发送恶意RPC请求，实现局域网内横向移动。 |  
| CVE-2010-2729 | Task Scheduler (任务计划程序) | **权限提升**：通过恶意`.job`文件，将普通用户权限提升至SYSTEM级。 |
| CVE-2010-2744 | Windows 内核驱动 (win32k.sys) | **深度隐藏**：执行内核态代码，绕过安全软件监控。 |

## 3. 针对工业控制系统的攻击链

### 3.1 Step7 工程软件劫持
震网将自身注册为恶意COM对象。当工程师使用西门子Step7软件与PLC通信时，这些恶意对象会被自动加载。
- **中间人攻击**：震网挂钩了Step7与PLC之间的通信API。
- **代码替换**：它拦截发给PLC的梯形图逻辑（.s7c文件），篡改其中的关键代码块，使其执行恶意逻辑，但软件界面上仍显示正常的代码。       

### 3.2 离心机破坏逻辑
攻击目标为西门子S7-315和S7-417型PLC，具体破坏逻辑如下：

1.  **频率探测**：持续监听频率转换器的工作频率。
2.  **条件触发**：当频率处于 **807Hz - 1210Hz**（离心机正常工作范围）时，启动攻击。
3.  **超频破坏**：将输出频率突然提高至 **1410Hz**，持续10-15分钟，导致离心机转子因超速产生共振而损坏。
4.  **虚假汇报**：在攻击期间，向中央监控系统回传伪造的正常转速数据，操作员无法察觉异样。

### 3.3 隐身与Rootkit技术
-   **文件过滤**：安装文件系统驱动（如`Mrxcls.sys`），当系统尝试读取恶意文件时，实时返回“干净”的版本。
-   **数字签名盗窃**：震网使用的驱动程序经过了**Realtek**和**JMicron**等公司的合法数字签名，绕过了Windows的驱动签名验证。
-   **长潜伏期**：病毒在感染后默认**等待约300天**才开始激活破坏行为，大大增加了溯源难度。

## 4. 传播与演进
震网的传播超越了传统蠕虫，利用了所有可能的内部网络渠道：
-   **U盘**：利用LNK漏洞实现“零点击”感染。
-   **网络共享与打印机服务**：在局域网内快速横向移动。
-   **Windows更新服务器**：攻击内部WSUS服务器，伪装成系统补丁进行分发。

**版本演进**：
-   **版本 0.5 (2009.6)**：早期测试版，核心攻击逻辑已存在。
-   **版本 1.0 (2010.3)**：大规模传播，主要利用MS10-046漏洞。
-   **版本 1.1 (2010.4)**：包含全部四个零日漏洞，集成Rootkit。

## 5. 影响与后续变种
震网病毒开创了网络攻击破坏物理世界的先河，其技术遗产催生了多个后续APT组织：

-   **Duqu (2011)**：用于间谍活动的“震网之子”，专注于收集工业情报。
-   **Flame (2012)**：复杂的网络间谍平台，用于中东地区的大规模监控。
-   **Gauss (2012)**：针对金融行业的恶意软件，与震网共享部分代码。

## 6. 总结
| 技术领域 | 具体手段 | 评价 |
| :--- | :--- | :--- |
| **漏洞利用** | 同时使用4个零日漏洞 | 史无前例 |
| **攻击目标** | 工业PLC (西门子) | 战略级 |
| **隐蔽性** | Rootkit、数字签名、长潜伏 | 极难发现 |
| **破坏效果** | 物理毁坏离心机 | 国家战略打击 |

**震网病毒的启示**：它证明了关键基础设施（核电站、电网、水厂）在网络攻击面前的脆弱性，标志着网络战争从“信息战”进入“瘫痪战”的新阶段。
